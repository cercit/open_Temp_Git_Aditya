FinStack hackathon: 15 ideas

Team: Sameer + Aditya · Lock the idea at our 3 pm call · Send the flowchart and screens before 8 pm today

What the brief asks for (every idea must cover these)

  • Onboarding: self-serve, assisted or hybrid, picked to suit the user
  • KYC through APIs (PAN, Aadhaar/DigiLocker). Mandatory; don't skip it
  • Pre-fill from API responses (e.g. name and DOB from PAN)
  • Underwriting through APIs: soft-pull bureau and bank statement
  • Rule engine: journey rules and underwriting rules
  • Manual approval for edge cases, handled in the back office
  • Dashboards and funnels

Their words: make it complete, sound and compliant, and don't pile on platform features to impress. Also from the session: a consent checkbox on the first form, onboard an individual (not a business), and use soft pull only.

Top 3 picks

#1 · Best pick

Used-car loan with RC check

Salaried buyerSelf-serve

Uses the vehicle/RC verification API that most teams won't touch. It tackles real fraud: the seller isn't the owner, or the car is still under an old loan. Sameer has worked in vehicle finance, so the rules will be realistic.

  • OTP
  • Consent
  • Basic details
  • PAN (pre-fill, name match ≥80%)
  • Aadhaar / DigiLocker
  • RC number (owner, age, hypothecation)
  • Soft-pull bureau
  • Bank statement
  • Offer

Rules: score <650 rejected · RC owner must match the seller · LTV based on car age. Manual review: score 650–700, a car still under another loan, or a car over 8 years old. Risk: the RC API may not be live on pre-prod, so mock it if needed.

#2

EV scooter loan for delivery riders

Swiggy / Zomato / Zepto ridersSelf-serve

A big underserved group with a strong story: gig workers get rejected for not having a salary slip. We'd underwrite from weekly platform payouts in the bank statement instead, the same "smart underwriting" style as FinStack's dairy-farmer client.

  • OTP
  • Consent
  • PAN + Aadhaar
  • Rider ID (custom form)
  • Bank statement
  • Soft pull
  • Rules
  • Offer

Rules: 4+ weeks of payouts, with the average above a set amount. Manual review: a thin bureau file (no score yet).

#3

Skill-course loan with a parent co-applicant

StudentsHybrid

The student has no income, so the parent's KYC and bureau decide the loan. A two-person journey shows we can use the journey builder well, and everyone in the room can relate. Watch out: co-applicant flows take longer to configure.
